01 · OWASP LLM10

All You Can Eat

One caller floods the model. A per-key rate limit answers HTTP 429 before the model is ever called.

Rate limits 02 · OWASP LLM10

Backstage Pass

An app key with no allowlist reaches every model on the gateway. One line in the key fixes it.

Model allowlists · access controls 03 · OWASP LLM10

Denial of Wallet

Rate limits don't cap cost. A per-key budget does, and it overshoots by exactly one request.

What's in the lab

Everything runs on one machine: Ollama serves the models (qwen2.5:7b for chat, nomic-embed-text for embeddings) and a LiteLLM gateway sits in front with per-caller virtual keys, rate limits, model allowlists and budgets, backed by Postgres. Each lesson comes as a manual walkthrough and an automated script that prints a PASS or FAIL verdict.

git clone https://github.com/DanHaggarty/BRBLab.git
cd BRBLab
powershell -ExecutionPolicy Bypass -File .\setup.ps1
powershell -ExecutionPolicy Bypass -File .\exercises\01-llm10-all-you-can-eat\run.ps1
BRB Lab is open source on GitHub. The lab is intentionally vulnerable: run it on your own machine, bound to 127.0.0.1.
